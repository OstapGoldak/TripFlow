# TripFlow — Desktop Travel Organizer

Десктопний застосунок на базі WPF та .NET для планування подорожей, структурування розкладу по днях, ведення бюджету витрат та організації чек-листів спорядження.

# Мета проекту
Створення єдиного автономного десктопного простору для планування поїздок, який об'єднує маршрути, фінансовий контроль та списки речей без використання сторонніх платних платформ.

# Проблематика
1. **Розкид інформації:** документи на пошті, квитки в галереї, розклад у месенджерах, а список речей у блокноті.
2. **Складнощі з бюджетом:** важко контролювати залишок коштів та незрозуміло, скільки ще можна витратити.
3. **Залежність від інтернету:** на відміну від веб-сервісів у роумінгу, десктопний застосунок надійно зберігає все планування офлайн перед виїздом.
4. **Рутинне пакування:** щоразу доводиться створювати списки речей з нуля, через що часто забуваються базові речі (зарядки, аптечка, документи).

# Вимоги до застосунку (Функціонал)
* **Створення поїздки:** внесення назви, вибір країни/міста, дат поїздки та встановлення планового бюджету.
* **Контроль маршруту та активностей:** генерація списку днів за датами, додавання активностей до кожного дня (час, локація, орієнтовна вартість, нотатки).
* **Фінансовий контроль:** внесення щоденних витрат за категоріями, динамічний розрахунок витраченої суми та залишку, контроль лімітів.
* **Списки спорядження (Чек-листи):** категоризація речей, відмітка спакованих позицій, збереження базових шаблонів.
* **Експорт даних:** вивантаження повного плану поїздки та звіту витрат у текстовий файл (.txt / .csv) для друку чи перегляду на телефоні.
* **Зручний інтерфейс:** фільтрація та швидкий пошук подорожей для простоти щоденного використання.

# Ролі користувачів
* **Мандрівник (User):** керування особистими подорожами, маршрутами, бюджетом та списками речей.

## Аналіз ринку та додатків-аналогів

Для виявлення сильних та слабких сторін існуючих рішень я провела порівняльний аналіз трьох прямих конкурентів у ніші тревел-планування (`TripIt`, `Wanderlog`, `Roadtrippers`).

| Засунок | Основний функціонал | Переваги | Недоліки |
| :--- | :--- | :--- | :--- |
| **TripIt** | Автоматичний парсинг пошти, імпорт квитків/броней, загальний таймлайн. | Висока автоматизація без ручного вводу, популярність. | Перевантажений інтерфейс, платна підписка (TripIt Pro) на важливі фічі, немає інструментів для щоденного обліку витрат і чек-листів. |
| **Wanderlog** | Інтерактивне планування маршрутів на карті Google Maps, спільне редагування. | Сучасний веб-інтерфейс, візуалізація точок на карті. | Повна залежність від інтернету (немає офлайн-версії), платна підписка для бюджетної аналітики та роботи з файлами. |
| **Roadtrippers** | Побудова складних автомобільних маршрутів, розрахунок зупинок (АЗС, готелі) та палива. | Відмінний розрахунок кілометражу, часу та паливних витрат. | Суто автомобільна орієнтація (не підходить для піших прогулянок, потягів чи перельотів), жорсткий ліміт точок у безплатній версії. |

### Конкурентні переваги TripFlow
* **Локальне збереження даних:** надійна десктопна база даних працює без інтернету, відсутній ризик втратити доступ до планів у роумінгу.
* **Універсальність:** поєднує в єдиному вікні погодинний розклад, чек-лист речей та жорсткий контроль бюджету без платних підписок чи лімітів на кількість записів.
